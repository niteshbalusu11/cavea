# Changelog

All notable changes to Cavea's published artefacts (the npm packages, the server and its image). Versions follow semver from 1.0 (`docs/05-web-sdk.md`); before 1.0 a minor version may break.

Pull requests do not edit this file. Their titles are the entries: at a release, `bun tools/changelog.ts` lists the titles merged since the last one and the releaser condenses them into the version's section (`docs/01-architecture.md` §6).

## 0.1.0 (unreleased)

The first version, not yet released.

- **Seat map for the web** (`@cavea/renderer`): `createSeatMap` draws a compiled chart with WebGL2 from WebAssembly, with selection rules, holds through a state adapter (`caveaServer`, `customState`, `staticState`), prices, a built-in interface (zoom, legend, tooltip, toasts, loading and error states), theme tokens, messages in any language, keyboard and screen-reader use, retries and cancellation, and `preloadSeatMap`. ES module with types, a script-tag build (`cavea.min.js`, `window.Cavea`) and a React component (`@cavea/react`).
- **Server** (`cavea-server`): workspaces, keys, charts, events, holds and bookings on PostgreSQL, realtime seat state over WebSocket, SSE and polling, the console's sign-in and roles, an OpenAPI document, metrics and a reconciler.
- **Designer and console**: the chart designer's edit core and its first panels, in the console.
- **Tools**: the `cavea` command line (generate, compile, validate, inspect, benchmark) and a load generator.
