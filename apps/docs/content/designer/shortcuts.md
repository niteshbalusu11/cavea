# Designer keyboard shortcuts

Every keyboard shortcut of the chart designer, for Windows and Linux and for macOS. The designer shows the same list itself: press **?** while it has focus.

Keys act where the focus is: while you type in a field, the field keeps its own keys (undo, copy, the arrows), and only **Save now** reaches the designer. While you are drawing, letters and digits go to the tool you are drawing with (to type a length, for example) instead of switching tools. This page is generated from the designer's own table of shortcuts, so it always matches it.
